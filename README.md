# Adopt_A_Pet
This project is all about building a full-stack dog adoption platform that uses computer vision and artificial intelligence to help users find adoptable dogs. Users can create an account and upload a picture of a dog, which is processed by a pretrained ResNet50 CNN fine-tuned on a dog breed dataset to predict the dog's breed. The predicted breed is then used with the RescueGroups API to find adoptable dogs of the same breed near the user's location. Users can browse available dogs, view adoption information, and save their favorite pets. The pipeline combines image classification → breed prediction → REST API → backend → database → frontend to create an easy-to-use AI-powered adoption platform.
